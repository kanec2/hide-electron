
# Справочник типов данных

Ключевые структуры данных, используемые для коммуникации между слоями.

## ArboristNode
Основной тип для представления узла дерева файлов в ReactArborist.

| Поле | Тип | Описание |
|------|-----|----------|
| `id` | String | Уникальный идентификатор (обычно абсолютный путь) |
| `name` | String | Отображаемое имя файла/папки |
| `isLeaf` | Bool? | `true` для файлов, `false` для папок |
| `children` | Array~ArboristNode~? | Дочерние элементы. `null` если папка не загружена |
| `isLoaded` | Bool? | Флаг ленивой загрузки. Если `false/null` — дети отсутствуют |
| `isLoading` | Bool? | Индикатор текущей загрузки детей |
| `path` | String? | Абсолютный путь к ресурсу |
| `relativePath` | String? | Путь относительно корня проекта |

## CreateHandlerArgs
Аргументы для создания новых сущностей.

| Поле | Тип | Описание |
|------|-----|----------|
| `parentId` | String | ID родительской папки |
| `index` | Int | Позиция вставки |
| `type` | String | `"folder"` или `"file"` |

## MoveHandlerArgs
Аргументы для перемещения (Drag & Drop).

| Поле | Тип | Описание |
|------|-----|----------|
| `dragIds` | Array~String~ | IDs перемещаемых узлов |
| `dragNodes` | Array~NodeApi~ | Объекты API перемещаемых узлов |
| `parentId` | String? | ID целевой папки |
| `parentNode` | NodeApi? | Объект API целевой папки |
